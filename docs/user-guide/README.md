# Mistty user guide

Everything you need to install, drive, configure, and script Mistty.

New here? Read [Installation](installation.md) and then [Getting started](getting-started.md) — together they'll get you from zero to a working multi-pane setup.

## Contents

- **[Installation](installation.md)** — Homebrew, optional zoxide, and building from source.
- **[Getting started](getting-started.md)** — the mental model (windows → sessions → tabs → panes), the sidebar, the session manager, and splitting panes.
- **[Keyboard shortcuts](keyboard-shortcuts.md)** — every default binding, indexed tab/session shortcuts, and window mode.
- **[Copy mode](copy-mode.md)** — vim-style scrollback navigation, selection, search, and link/path hints.
- **[Configuration](configuration.md)** — the complete `config.toml` reference, including Ghostty passthrough.
- **[CLI](cli.md)** — controlling Mistty from the terminal with `mistty-cli`.
